# 🎓 Lições Jovens Q3 2026

**Aplicação web interativa** para Escola Sabatina Jovem com foco em **memorização científica** e **engajamento**.

---

## ✨ Features

### 🧠 **Fase 1: Spaced Repetition + Interleaving + Streak**
- **SM-2 Algorithm**: Repetição espaçada científica (1 → 3 → 7 → 14 → 30 dias)
- **Interleaving**: 30% de questões antigas para revisar
- **Streak Manager**: 🔥 Rastreia dias consecutivos estudando
- **localStorage**: Dados persistem no navegador

### 📊 **Fase 2: Radial Mental Maps (Sábado)**
- Mapa visual SVG com 7 cores dos dias
- Centro = Palavra-chave da lição
- Síntese pedagógica da semana
- Renderização dinâmica

### ✅ **Fase 3: Feedback Melhorado**
- Caixa visual com ✓ (verde) ou ✗ (vermelho)
- Explicações de cada questão
- Próxima data de revisão
- Integrado com SM-2

### 🌙 **Features Originais**
- Dark mode com toggle
- "Continue seu Plano Bíblico" (Gênesis 1-3)
- 5 abas: Início, Bíblia, Lições, Progresso, Conta
- Design premium com gradients
- 13 lições completas + 910 questões

## 🚀 Como usar

### Local
1. Baixe `licoes-app-v3-FINAL.html`
2. Abra no navegador (Chrome, Firefox, Safari)
3. Dados são salvos em `localStorage` automaticamente

### Online (Cloudflare Pages)
1. Crie repositório no GitHub
2. Conecte em **Cloudflare Pages**
3. Auto-deploy a cada push
4. URL: `seudominio.com` (customizável)
